# Prime Energies website

Static website for **Prime Energies (Pty) Ltd**: data, AI and energy technology for the industries that power South Africa.

- `index.html`: Home
- `solutions.html`: overview of the three practices
- `mining-intelligence.html`, `energy-utilities.html`, `enterprise-systems.html`: one page per practice
- `platform.html`: Operations intelligence platform
- `insights.html`: Market Pulse (curated industry news, each item linked to its source)
- `company.html`: About, approach and credentials
- `contact.html`: Contact details and briefing request form
- `404.html`, `robots.txt`, `sitemap.xml`, `favicon.ico`, `assets/og-image.png`, `assets/icon.svg`, `assets/apple-touch-icon.png`: error page, search and sharing files
- `assets/site.css`, `assets/site.js`: shared styles and behaviour (console tabs, mobile menu, contact form)

No build step: plain HTML, CSS and JavaScript, served by GitHub Pages from the `main` branch root.
